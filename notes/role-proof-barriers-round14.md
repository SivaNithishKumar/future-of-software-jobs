## What the proposed proof can show

Each paragraph names an existing artifact; the JSON gives the individual skill-to-diagnostic mapping and acceptance oracle. All work remains proposed and subject to the original resource, data-rights and installation gates.

**GitLab → versioned multi-tenant ingestion/recovery.** Implement or audit one API/schema boundary, query/migration behavior, duplicate/delete replay and a seeded performance/recovery failure. Review a planted incorrect AI-generated patch through the existing retained-skill diagnostic, then write an asynchronous decision/handoff record. Independent expected states and fresh failure cases are the oracle. This does not supply production years, all optional stack skills or actual team ownership.

**LabVantage → synthetic controlled workflow plus adversarial evaluation.** Test Python/REST authorization, multi-tenant state and repeatable agent recovery. Reproducible local Docker packaging and a clearly marked AWS design boundary are useful evidence. A diagram is not hands-on AWS operation; a synthetic laboratory workflow does not establish safe instrument execution, biological validity or the required senior experience.

**Met Office → issue/receipt-lineage weather replay.** Diagnose a wrong-unit, future-data, station/time or missingness defect; state requirements and fallback behavior, test them independently and explain the result. This is scientific-software QA evidence. It is not a new weather model, 100 m urban-model expertise, research-grade meteorology, grade equivalence or a substitute for UK residence/work eligibility.

**Riverlane → tiny compiler transform/equivalence proof.** Use Python plus the relevant C++/Rust boundary, trace IR/data/control flow and catch a semantically invalid transformation with a classical oracle. State which OS, architecture and LLVM/MLIR skills remain untested. Tiny circuit equivalence is not production compiler depth, quantum application advantage or real-time hardware competence. Software work within a quantum company is a distinct route from quantum research science.

**Synopsys → constrained FIFO RTL-to-physical flow.** Connect a tiny netlist/graph routine to checked behavior and reproducible reports. Explain reset, wraparound and stall invariants before changing the design; hold timing constraints fixed and record unsupported FPGA claims. This tests relevant software/RTL slices. It supplies neither two professional years, the employer's degree requirement, industrial partition scale nor tapeout/silicon validation.

**lowRISC → the same EDA project or compiler prerequisite slice.** A small C/Rust report/parser/checker can expose algorithmic reasoning, corrupt-input handling and reproducible builds. An English incident/handoff explanation and a narrow compiler-build trace can be reviewed separately. This does not demonstrate secure firmware, assembly, every valued build tool or an accepted upstream contribution. The Senior/Principal scope remains; this employer's degree-equivalence option does not erase other firms' degree gates.

**Aeva → degradation-aware localization replay.** Derive a frame transform/filter update, trace C++/Linux and Python/Bash integration, diagnose calibration/timestamp failure and measure error, coverage and tail runtime on untouched sessions. Ground truth stays scoring-only. ROS familiarity and replay performance do not establish real-time perception deployment, graduate qualifications, vehicle safety or field competence.

**MVTec → validation-fixed inspection decision report.** Produce a feasibility/threshold report and a useful support/training handoff, with independent part labels, false alarms/misses and explicit abstention. The optional language implementation and German/English explanation need their own acceptance. This does not supply B2 proficiency, technical degree, several years of automation, customer acceptance or production-line commissioning.

**Bentley → IFC validation/diff and versioned asset joins.** Test units/schema/application coverage, deterministic ingestion, identity across revisions, transactions, duplicate replay, rollback and observability. A C#/.NET adapter is a relevant implementation choice, while Azure operation remains unproved without authorized execution. The artifact is not building-engineering sign-off, true site state, seven years of cloud work or permission to work remotely from India.

**Public Health Wales → the existing synthetic data/recovery and authorization suite.** Test C#/.NET/SQL contracts, packaging, deletion/isolation and privacy failure cases using synthetic records. This can explain ordinary software responsibility inside public health. It cannot reopen a closed advert, establish NHS experience, clinical safety approval, patient-data access or immigration eligibility.

**Isomorphic → matched-quality inference bottleneck.** Preserve workload and output quality, include failed/cold-start runs and diagnose one latency/resource/reliability bottleneck. Measure GPU/Kubernetes/GCP behavior only on resources actually available and approved; otherwise those skills remain untested. This is software infrastructure evidence, not drug-discovery competence or a staff-level record. The company's scientific mission does not make every software role a research-scientist role.

**Toronto staff scientist → simulated lab runner with an explicit research question.** State controls, uncertainty, an independent resource/state oracle and the distinction between reproducing a result and a novel contribution. A separately authorized scientific reviewer would be needed for domain validity; without one, leave it unassessed. This is a prerequisite/research-readiness diagnostic. It does not supply a PhD/equivalent research record, publications, major-project leadership, years of work or physical-lab competence.

## How to use the contrast

First identify a prerequisite that is actually unknown and choose one bounded diagnostic from an existing project. Preserve the independent oracle and all failed cases. Next distinguish what the artifact demonstrates from qualifications, experience, language, site access and work rights it cannot replace. Only an actual employer's criteria can settle whether an equivalence route is accepted.

The selected examples deliberately include ordinary software in scientific/frontier organisations, specialized engineering, scientific leadership, a closed health advert and imperfect indexed receipts. UKAEA's narrow graduate HPC route and Autodesk's indexed senior examples were not added merely to enlarge the count. No numerical fit score, individual hiring probability, five-year advancement timetable or representative job-market conclusion follows from these twelve.

Source hashes authenticate the saved reports/records used for curation. They are not hashes of freshly fetched live job pages. The matrix's missing fields and recorded dates must remain visible in any final role cards. No applications, outreach, private-profile checks, installs, model runs, physical operation or shared catalog/tree changes were performed.
